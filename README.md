# IEOR 222 · Financial Engineering

Lecture notes with proofs, exercises, and interactive Python demos for IEOR 222
(Financial Engineering, UC Berkeley, Industrial Engineering & Operations Research), by [Alberto Gennaro](https://gennaroalberto.github.io/).

**Read online:** [lecture notes (PDF)](https://gennaroalberto.github.io/ieor222-financial-engineering/notes.pdf) ·
[exercises (PDF)](https://gennaroalberto.github.io/ieor222-financial-engineering/exercises.pdf) ·
[download page](https://gennaroalberto.github.io/ieor222-financial-engineering/)

The PDFs are rebuilt from the LaTeX sources on every push, after the code tests and the notebooks have run.

These notes grew out of my own notes from taking the course as a student and from the
discussion sections, worksheets and exercises I later prepared as its graduate student
instructor (GSI). The general flow follows the lectures of Professor Thibaut Mastrolia,
whom I thank for the structure of the course and for his great teaching. Any mistakes are mine.

## Layout

```
latex/
  toc.tex            the chapters, in order: one list drives every PDF
  chapters/          lecture notes, one file per chapter
  exercises/         exercises, one file per chapter (statements only)
  figures/           figures, generated by code/figures/
  coursenotes.sty    shared style: statements, exercises, links to the code
code/
  src/ieor222/        a small Python package used by the notebooks and figures
  notebooks/         interactive demos, one or more per chapter
  figures/           scripts that draw the figures in the notes
  tests/             checks of the code against closed-form results
```

## Run the demos

Each notebook opens in Google Colab from the link in the notes. To run them locally:

```bash
pip install -e "code[dev]"
jupyter lab code/notebooks
```

## Build the PDFs

You need a TeX distribution (MacTeX or TeX Live) and Python 3.10 or later.

```bash
make            # figures, then latex/notes.pdf and latex/exercises.pdf
make test       # code tests
```
